# Image exports

Board images from the Altium project for the **Smart Bike Theft Tracker**
(DTU 34374 final project, Group 11).

| File | View |
|---|---|
| `schematic-top.png` | Top-level hierarchy — four sheet symbols and the harness ports between them |
| `schematic-power.png` | `BatteryCharger.SchDoc` — USB-C, MCP73831 charger, TPS63001 buck-boost |
| `schematic-mcu.png` | `MCU.SchDoc` — STM32WL5MOCH6TR and the LoRa SMA feed |
| `schematic-gyrosense.png` | `GyroSense.SchDoc` — ADXL345 accelerometer |
| `schematic-gps.png` | `GPS.SchDoc` — NEO-6M, U.FL antenna and backup cell |
| `pcb-layout-top.png` | PCB top-copper layer — RF feeds, 3.3 V rail and connector placement |
| `pcb-3d.png` | Isometric 3D view of the assembled board |

The native design files — schematics, PCB, symbol/footprint libraries, the
schematic PDF and the STEP 3D model — are in
[`../../hardware/`](../../hardware/).
